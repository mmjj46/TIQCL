📘 DAQ 기반 실시간 P 제어 + 노이즈 실험 정리
🎯 실험 목적

DAQ 장비를 사용하여 간단한 폐루프 제어 시스템을 구성하고,

기준 신호(Reference)를 생성

아날로그 입력을 읽음

측정값에 외란(노이즈)을 인위적으로 추가

P 제어를 통해 보정값 계산

아날로그 출력으로 다시 인가

기준 / 입력 / 출력을 동시에 비교

함으로써 제어기의 동작과 외란에 대한 반응을 확인한다.

이 과정은 이후 FPGA에서 수행할 제어 로직을 PC 환경에서 미리 검증하는 단계이다.

🎯 시스템 구성
Reference → (오차 계산) → P Controller → AO 출력
                     ↑
                 AI 입력 + Noise


그리고 AO0 → AI0 를 물리적으로 연결하여
출력이 다시 입력으로 들어오는 폐루프(closed loop) 구조를 만든다.

🎯 사용 채널

입력: Dev3/ai0

출력: Dev3/ao0

전압 범위: ±10V

🎯 코드 동작 흐름

프로그램은 아래 순서를 무한 반복한다.

기준 생성 → 전압 읽기 → 노이즈 추가 → 오차 계산 →
P 제어 → 출력 → 그래프 업데이트

📌 1. 기준 신호 (Reference)

두 가지 모드를 선택할 수 있다.

Step

일정 시간 이후 특정 값으로 점프.

Sine

시간에 따라 사인파 생성.

setpoint = SINE_AMP * np.sin(2*np.pi*SINE_FREQ*t)


→ 제어기가 목표로 따라가야 할 값이다.

📌 2. 입력 읽기 (Measurement)
sensor = ai.read()


DAQ가 현재 AI0 전압을 읽는다.

📌 3. 외란(노이즈) 추가
noise = np.random.normal(0.5, NOISE_STD)
sensor_noisy = sensor + noise

의미

실제 시스템에서는 센서가 완벽하지 않기 때문에
측정값에는 항상 오차나 잡음이 포함된다.

이를 인위적으로 만들어
제어기가 방해를 받는 상황을 재현한다.

파라미터

0.5 → 평균 오프셋 (bias)

NOISE_STD → 랜덤 흔들림 크기

값을 키우면 시스템이 더 어려워진다.

📌 4. P 제어
error = setpoint - sensor_noisy
output = sensor_noisy + kp * error

의미

현재 값이 목표에서 얼마나 떨어져 있는지 계산하고,
그 차이에 비례해서 보정한다.

kp (Proportional Gain)

크면 → 빠르게 따라가지만 진동 가능

작으면 → 안정적이지만 느림

📌 5. 출력
ao.write(output)


계산된 제어 전압을 실제 장비로 보낸다.

지금은 AO0 → AI0 로 연결되어 있으므로
이 값이 다음 루프에서 다시 읽히게 된다.

📌 6. 실시간 그래프

세 가지를 동시에 보여준다.

Reference → 목표

Input → 노이즈 포함 현재 상태

Output → 제어기가 만든 보정 결과

이걸 통해

✔ 얼마나 잘 따라가는지
✔ 노이즈가 있어도 유지되는지
✔ kp에 따라 차이가 나는지

확인할 수 있다.

🎯 이 실험으로 확인 가능한 것

폐루프가 정상 동작하는지

제어 출력이 목표를 향해 수렴하는지

외란이 있을 때 얼마나 흔들리는지

kp 값이 성능에 어떤 영향을 주는지

🎯 FPGA와의 연결성

나중에 FPGA가 하게 될 일:

ADC 읽기 → 오차 계산 → 제어 알고리즘 → DAC 출력


지금 코드는 이 전 과정을 소프트웨어로 그대로 모사한다.

즉,

✔ 알고리즘 검증
✔ 파라미터 감 잡기
✔ 시스템 반응 이해

를 미리 끝내는 준비 단계이다.
